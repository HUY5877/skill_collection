# WeMD 语法参考（微信公众号）

目标编辑器：https://edit.wemd.app/ 。正文必须用它支持的 Markdown。下面是语法速查 + 微信平台的关键注意事项。

## 基础语法

- 加粗：`**加粗**`
- 斜体：`*斜体*`
- 加粗斜体：`***加粗斜体***`
- 删除线：`~~删除线~~`
- 高亮：`==高亮==`
- 链接：`[文字](https://example.com)`

## 特殊格式

- 上标：`E=mc^2^`
- 下标：`H~2~O`
- Emoji：`:sunny:` `:books:` `:rocket:`（用得克制，别堆砌）

## 列表

无序：
```
- 列表项
  - 子项
```
有序：
```
1. 第一步
2. 第二步
```

## 引用与提示块

多级引用：
```
> 一级引用
> > 二级引用
```

提示块（很适合放「踩坑 / 提醒 / 重点」，善用它提升排版质感）：
```
> [!TIP]
> 技巧提示

> [!NOTE]
> 备注

> [!IMPORTANT]
> 重要信息

> [!WARNING]
> 警告

> [!CAUTION]
> 危险 / 强警告
```

## 代码

行内代码：`` `console.log()` ``

代码块（带语言高亮）：
````
```javascript
function hello() {
  console.log('Hello, WeMD!');
}
```
````

## 数学公式

- 行内：`$E=mc^2$`
- 行间：
```
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
```

## 脚注 / 链接

- 给链接加「标题」（双引号里的文字），WeMD 会**自动把它转成文末脚注**：
  `[WeChat Markdown](https://github.com/xxx "这是标题")` → 正文显示上标 `[1]`，网址收到文末。
- 这是最符合公众号习惯的排法（正文干净、URL 收尾部）。

## 表格

```
| 姓名 | 年龄 | 职业 |
| :--- | :---: | ---: |
| 张三 | 18 | 工程师 |
```
（`:---` 左对齐，`:---:` 居中，`---:` 右对齐）

## 其他

- 分割线：`---`
- 图片：`![alt 文字](https://img.url/x.jpg)`

## 微信平台注意事项（务必遵守）

1. **外部链接在公众号正文里点不动**：微信只允许白名单域名和跳转其他公众号文章的链接可点。GitHub、普通网址等发出去都不可点击。
   - 想让读者能用的网址，**用行内代码或纯文本把完整 URL 摆出来**让人复制，例如：`` `https://github.com/xxx/yyy` ``。
   - 或者用「链接加标题」变成文末脚注，把 URL 列在文末（点不动，但可见可复制）。
   - 不要用普通 `[文字](url)` 假装可点——发到公众号是死链。
2. **表格列数别太多**：手机端阅读为主，超过 4~5 列会很挤。信息多时优先拆成「每项一段 + 小标题」或精简列。
3. **中文标题不要烤进封面图**：AI 生成中文字容易糊，标题交给公众号自带的标题叠加；图里最多放短英文字样。
4. **标题（最顶部的 `#`）**：作为文章大标题，正文其余小节用 `##` / `###` 分层。
