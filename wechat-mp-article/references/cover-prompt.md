# 封面提示词模板（微信公众号 · 一图两用）

把这段提示词交给任意文生图能力使用。用时只改「画面内容」和「风格」两处，其余格式约束原样保留。

> 生图的具体实现方式由运行环境自行决定，本模板不绑定任何服务商/接口。

## 提示词模板

```
请根据文章内容生成一张微信公众号封面图,严格遵守以下格式规则:

【画幅】横向 21:9 宽幅长图(约等于微信 2.35:1 封面比例),分辨率 2k。

【一图两用的核心约束】这张图要同时满足微信的两种裁切:
1. 完整宽图用作消息列表大图(2.35:1);
2. 从图片正中央裁一个正方形用作转发卡片和公众号主页(1:1)。
因此,所有核心元素(主体、标题文字)必须全部集中放在画面【正中央的正方形安全区】内——保证从中心裁出正方形时,主体和标题都完整不残缺、不被切到。

【两侧处理】画面最左侧和最右侧只放可以被安全裁掉的装饰元素(如淡淡的漂浮代码片段、简单科技小图标、色块),不放任何关键信息。

【文字】文字尽量简洁,放在中心区域内,英文优先(避免中文字符渲染出错);不要出现乱码、错字、水印。

【画面内容】<结合本篇文章主题描述画面。例如:一个憨憨的白色机器人坐在桌前用笔记本敲代码,旁边漂浮一个深色终端窗口显示彩色代码,中心下方有 'Claude Code' 小字样>

【风格】<写画面风格。例如:扁平等距矢量插画,暖色编辑风,米白+赤陶橙,柔和光影,留白充足,干净高级>
```

## 为什么这样写

- **用 21:9 而非直接写 2.35:1**：多数模型认 `21:9`（≈2.33:1），与微信 2.35:1 几乎一致，识别更稳。
- **「正中央正方形安全区」是命门**：微信的 1:1 是从上传的宽图里拖方框裁的、默认取中间，所以主体和标题必须锁死在中心，两侧只放可丢弃的装饰——这样宽图完整、方图裁中间都不残。
- **文字优先英文 + 禁乱码**：AI 生成中文字容易糊，标题类文字建议只放短英文。
- **分辨率 2k**：封面清晰不糊。
